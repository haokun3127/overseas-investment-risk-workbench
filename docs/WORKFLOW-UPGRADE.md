# 工作台功能完善记录 · 2026-09-12

## 采用的技能

- `redesign-existing-projects`：在现有 FastAPI、SQLite、原生 JavaScript 架构上补强页面，避免无必要的框架迁移。
- `Impeccable / harden`：完善输入校验、异步反馈、数据为空、请求失败、草稿恢复和移动端使用。
- 保留用户指定的蓝白操作色，以及现有深蓝工作区；风险等级使用独立语义色。

## 各模块交付

| 模块 | 本轮增加 | 使用方式 |
| --- | --- | --- |
| 风险总览 | 模型配置、规则确认、真实资料、知识库四项准备状态；尚无分析结果的真实资料数量 | 从准备清单进入对应页面；知识库为可选条件 |
| 风险事件 | 根据当前筛选导出完整 CSV 台账；日期起止校验 | 导出包含摘要、影响、建议、复核意见、版本及引用；不只导出当前页 |
| 事件详情 | 每次复核结论与意见的历史记录；返回保留列表筛选 | 展开“复核历史”；已有旧复核在下一次保存时纳入历史 |
| 资料导入 | 按来源检索、授权范围和分析状态筛选；文件前置校验；当前选中数量 | 资料列表查询；最大10MB；批量分析沿用服务端规则和授权检查 |
| 手动录入 | 同一页面会话内的草稿暂存、正文字符数 | 跳转其他模块再返回可恢复；刷新或关闭页面清除，成功保存后清除 |
| 知识库 | 真实参考资料数量、字符数、允许外部分析数量；检索中反馈 | 全部统计来自本地数据库；检索保留原文入口 |
| 分析任务 | 按资料标题或任务编号检索、按状态筛选、匹配数量 | 筛选范围是最近100条任务，后台刷新时保留已提交筛选 |
| 模型与规则 | 业务表单编辑分类、等级、版本和说明；连接检查；最近操作记录 | 连接检查仅发送固定合成内容，验证连接和基础 JSON 协议 |

## 数据与兼容性

- 新增 `review_history` 表，应用启动时创建，不删除既有数据。
- 复核更新与历史写入在同一个 SQLite 事务中完成。
- CSV 使用 UTF-8 BOM，兼容中文 Excel；防止以公式字符开头的字段被作为公式执行。
- 导出遵循原有“每份资料最新分析版本”与真实/演示筛选。
- 新接口沿用管理员会话、同源校验和变更请求标记。
- 模型密钥仍只在服务端配置。点击连接检查可能产生少量 API 调用费用，页面已说明。
- 操作日志显示最近15次已记录操作，不作为多用户身份审计系统。

## 仍需要的甲方输入

真实模型凭据、甲方确认的分类分级规则、脱敏样本及服务器资源尚需提供。连接测试使用模拟响应做自动化验证，不表示已连接真实供应商。识别准确率、召回率、时延和本地模型选型需在真实条件下评估。

当前仍为单管理员、单进程、本地部署的一期系统；自动采集、多角色审批、持续监控与集群部署不属于本轮已交付内容。
