# 补证、正文版本对比与规则快照交付

交付日期：2026-10-24（北京时间）。版本：`20261024-evidence2`。

## 使用入口

- 主导航“待补证”，总览业务待办中的补证数量，以及资料列表“证据不足”后的“补充证据”。原文分析记录也能进入对应补证版本。
- 网站检索结果中的“正文变化”筛选和每个页面的“查看更新对比”。
- 提交分析前显示当前规则版本；历史分析记录显示实际使用的规则版本。

## 补证流程

队列只收集非演示、未隔离资料的最新“证据不足”分析。列表显示简短原因，详情保留各段完整说明。企业只能访问本公司记录，管理员可查看全部。

可保存补充文本或上传 Word、文本 PDF、TXT/Markdown、单条记录表格；扫描件需先 OCR。每条原资料最多关联10份材料，正文合计不超过24000字符，单个附件不超过10MB。材料保持原资料的公司归属，使用独立用途保存，不自动进入公共知识库。

保存材料和提交重新分析是两个操作。原资料和全部关联材料均需授权外发，隔离材料不能使用。排队时保存补充正文、材料编号、公司背景和规则；模型引用可定位到补充材料原文。重新分析保留旧版本，最新结果仍为证据不足时继续留在队列，形成风险或非风险结论后进入“已形成结论”。风险事件继续按原有复核流程处理，不自动认可。

普通资料页重新提交也会带上已关联材料，避免通过另一入口重试时遗漏补证。任务执行期间禁止移除材料关联、撤销被使用材料的授权或删除被使用材料。移除关联保留材料原文及历史分析。

## 网站正文版本对比

以同一网站来源、完全相同的网址和上一次成功任务的保存快照为基线，不使用失败或未来任务。提供新增快照、正文更新、未变化和采集方式变化四种状态。

差异显示新增、删除和上下文，提供本次/上次完整原文及采集时间。忽略空白格式差异；在线页面与历史存档之间的切换标为不可直接比较，不当作网站新更新。“新增快照”仅表示首次保存这个网址，不代表发布于当天。

仅在展开时计算正文差异，不调用模型；展示最多240行、60000字符，超过时明确提示并保留完整原文入口。筛选会取消隐藏页面的勾选，全选仅作用于可见页面。对比结果不自动修改知识库、政策有效性或风险等级。

## 规则快照

手动提交、网站入库自动分析、补证重新分析均在入队事务中保存确认后的完整规则，执行时只读取该快照。排队期间修改或取消确认全局规则，不影响已经提交的任务。

历史排队任务若没有快照，只能在升级时固定当时规则，并明确记录 `upgrade` 来源，不能追认成提交时快照。历史已完成分析继续保留其实际使用的规则，不补造提交记录。
