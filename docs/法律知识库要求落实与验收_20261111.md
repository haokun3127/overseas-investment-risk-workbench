## 已实现的业务操作

知识库导入时可选择14类知识资源，另有未分类项。每份资料可维护国家或地区、文号、发布机构、生效与失效日期、效力状态、人工核验日期、核验说明和原文网址。非“未确认”的效力状态必须同时有日期、依据及网址，不由大模型自动认定。交叉印证状态由人工维护，选择确认时要求两个不同网站来源及独立性核验说明；不同域名本身不证明来源独立。

新导入资料按固定标题识别事实认定、法律适用、法院或仲裁庭认为、裁判主文、执行情况。支持部分中文、印尼文、英文标题。段落内部仍按2400字符划分，保存原文字符起止位置。未识别内容保留为正文；不声称已实现任意司法文书的语义分类或训练模型。旧片段编号和正文保留，增加可精确定位的结构片段；不改写历史引用。

知识库列表支持分类与效力筛选，检索支持分类、段落与效力组合条件。混合检索结果再次按条件过滤，不允许向量候选绕过范围；指定裁判段落时预览仅显示对应片段，完整原文仍可打开。

咨询页面提供普通问答及四模块咨询报告。法律依据模块限定法律法规或条约等类别且有人工确认的现行有效记录；类似案例模块限定判决、仲裁或案例类别的裁判理由段落。各模块均须通过原文引文和金额一致性检查，无依据模块列入缺口。报告保存完整回答与引用快照，可下载Word或通过浏览器打印为PDF，导出接口再次核对当前企业范围。国别化评分及权重未确认时不生成量化分数。

## 使用路径

知识库 → 上传或手动录入 → 选择分类及适用地区。已有资料 → 查看详细 → 维护分类与法规效力。咨询问答 → 输出形式选择咨询报告 → 输入事项 → 查看有依据模块与缺口 → 下载Word或打印PDF。

原有资料默认未分类、效力未确认。不能因为来自官网就自动确认现行有效，也不能因为有两个链接就自动认定独立来源印证。历史分析、原始资料和此前19组案例的参考答案不会被用来自动补写法规效力。

## 测试边界
