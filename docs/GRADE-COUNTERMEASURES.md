# 五级分级对策参考

工作台按《风险预警分级1027》的红、黄、蓝、灰、绿五级分别查阅企业层面和国家层面对策。旧清单中的“高、中、低”不再用于这个入口；历史记录若保留旧等级，会提示复核，不直接换算。客户清单允许的“对不上”是指标分类，和预警等级分别处理。

## 展示与使用

- 侧栏“分级对策库”：选择等级，查看原文预警标准、阈值、两类可选对策和来源，支持下载原始 DOC。
- 事件详情：按事件**已保存**的等级显示参考。模型针对事件生成的建议与原文对策分列，不把整套原文当成针对该事件的推荐。
- 事件列表的就地核验：提供当前等级对策入口。
- 风险简报：只汇总当前筛选结果涉及的等级，每个等级一次，避免逐事件重复附录；打印保留原文出处。

原文阈值只是文件规定的标准区间，不表示系统已经计算出某个事件的概率或评分。国家层面对策需由有权机构评估、协调。展示参考不自动采取任何处置措施。

## 私有原文数据

代码仓库只包含通用读取器、界面和合成测试。客户原文与提取数据部署在数据目录，不提交 Git：

```
DATA_DIR/reference-data/grading-1027/bank.json
DATA_DIR/reference-data/grading-1027/source.doc
```

`source.doc` 为原始文件字节。`bank.json` 使用 schema_version=1，包含 `source`（标题、版本、章节、SHA-256）和 `levels`（lv1 至 lv5）。每级有 `label`、`threshold`、`standard`、`standard_locator`，以及 `enterprise`、`state` 两个数组。每项包含 `id`、原文 `text` 和表格行列 `locator`。数组保留原表次序。当前来源提取到企业45项、国家18项；这是各等级条目合计，不代表63项不同措施。

服务会校验源文件 SHA-256、五级完整性、必填字段、大小和路径范围。缺失、损坏、源文不匹配时明确显示“原文暂不可用”，不编造替代建议。下载路径固定，登录后可访问，不接受用户任意文件路径。

## 数据和权限边界

此功能在读取响应时附加参考，不重跑模型，不更新事件的分类、等级、建议或证据，也不把参考文件混入企业文档与向量库。事件与简报沿用原有企业访问范围；公共参考库不赋予查看其他企业事件的权限。三个客户预期“对不上”的案例无需强制映射到45项指标。

## 验证

`tests/test_countermeasures.py` 使用合成内容验证登录、来源下载、等级匹配、筛选汇总、历史等级拒绝套用、原文损坏、租户隔离和路径越界。页面核对五级全部条目、手机布局及打印，并比较下载原文的 SHA-256。部署前后另比较业务表摘要，确认既有分析结果未被改写。
