# 网站检索使用说明

## 操作流程

1. 运维在安全配置处设置 `SEARCH_PROVIDER=tavily`、`SEARCH_BASE_URL=https://api.tavily.com`、`SEARCH_API_KEY` 和可选 `SEARCH_TIMEOUT=60`，重启单进程后端。首次适配 Tavily；新增供应商需实现 `app/websites.py` 的 provider 接口。
2. 登录工作台，打开“网站检索”，添加网站名称和公开 HTTPS 网站或栏目。可编辑、启用或停用来源；不预置目标网站。
3. 选择来源，填写主题或关键词、可选日期范围及结果上限，发起检索。相同条件的未完成任务会复用，近期任务可查看结果，失败后可按原条件重新检索。
4. 展开候选资料的摘要和正文快照，核查原始链接和发布时间；确认用途后点击“加入知识库”或“加入待分析资料”。可分别用于两个用途。
5. 如允许外部分析，明确勾选正文外发授权。默认不授权；已入库资料的授权需要在“查看原文”中修改，重复入库不改变权限。
6. 在资料列表选择待分析资料，执行既有分析前检查、规则确认和模型分析。在风险列表查看站内风险事件、来源与复核意见。分析需要独立配置 `MODEL_*`。

## 保存与判断边界

- 检索通过 Tavily `POST /search`，使用域名筛选、`include_raw_content=text`、可选起止日期，不请求 AI 综合答案作为证据。后端再次核验结果 URL 和栏目路径。检索主题、网站范围及日期会发给外部服务。
- 保存的是服务返回的**正文文本快照**，不是独立访问网页获得的完整 HTML，也不保证网页完整性或搜索覆盖率。若服务提供最终跳转地址，会再次校验范围；未提供时无法独立验证跳转去向。
- 搜索摘要独立保存；没有正文或正文超过60000字符的结果仅保留线索，不能直接入库。不能使用摘要冒充原文。
- 发布时间来自服务返回字段，未知时间明确标识。设置时间范围时，发布时间未知的资料不能入库；可去掉时间限制重新检索并人工确认。不能把采集时间视为发布时间。
- 候选正文版本按来源链接与标题、日期、正文摘要校验值去重。同一来源的新正文形成新版本，对应独立资料，旧资料及旧引用保留。相同文字来自不同来源时保留各自来源身份，不合并来源证据。
- 同一版本和用途重复导入复用已有资料，不重复建索引。同一资料重新分析沿用现有历史版本机制，风险列表展示最新分析；不实现跨网站风险事件自动合并。
- “忽略”针对候选结果，不删除已入库资料。已导入结果不能忽略；未导入的忽略结果不能入库，可重新检索后再确认。
- 检索任务为持久化的排队、运行、完成、部分可用或失败状态。来源配置在提交时形成快照；之后修改来源不改变已提交任务的范围。重启中断的运行任务标记失败，尚未执行的排队任务继续运行。
- 模块复用认证、同源请求校验、审计、SQLite 备份与正文引用校验。继续使用单机单进程；检索队列与风险分析队列各有独立任务循环。
- 不包含定时采集、独立网页爬虫、登录网站、OCR、外部通知或实际业务效果保证。检索失败不会返回虚构演示结果。

## 后端接口

所有接口要求登录；写入操作需要既有 `X-Requested-With: risk-workbench` 请求头。

| 接口 | 用途 |
| --- | --- |
| `GET /api/websites/config` | 服务类型、是否配置及检索 worker 状态，不返回密钥 |
| `GET /api/websites/sources` | 来源清单 |
| `POST /api/websites/sources` | 新增来源，字段 `name,url,enabled` |
| `PUT /api/websites/sources/{id}` | 编辑来源及启停状态 |
| `POST /api/websites/searches` | 提交任务，字段 `source_ids,query,date_from,date_to,limit` |
| `GET /api/websites/searches` | 最近30个任务及结果数量 |
| `GET /api/websites/searches/{id}` | 来源快照、状态、错误、候选摘要、正文及已入库资料关联 |
| `POST /api/websites/results/{id}/import` | 确认入库，字段 `kind=knowledge或event,allow_external` |
| `POST /api/websites/results/{id}/ignore` | 忽略未导入候选 |
| `GET /api/documents/{id}` | 既有资料详情，新增 `website_origin` 来源版本及采集元数据 |

数据表在应用启动时以增量方式创建，不修改或删除现有资料。升级前按 README 备份数据库和附件；来源版本、检索任务和资料关联随 SQLite 一起备份。

## 验证

后端回归：

```bash
.venv/bin/python -m pytest -q
```

新增测试覆盖：来源范围和输入验证、服务协议、失败和重启状态、摘要与超长正文限制、日期不明、版本与去重、不同来源保留、默认不外发、知识检索及风险分析引用链路。

浏览器使用单独的受控服务及随机生成的 `qa/website-browser-*` 数据目录，全部结果明确为合成测试资料，不使用真实供应商、不写正式 `data/`。测试入口仅供验证，不用于日常启动：

```bash
# 终端一，确保端口8001未被其他服务占用；每次重启生成新的隔离测试库。
.venv/bin/python -m uvicorn scripts.ui_websites_server:create_test_app --factory --host 127.0.0.1 --port 8001
# 终端二，需要安装Playwright和Chrome，或使用平台提供的浏览器适配。
node scripts/ui_websites_test.cjs
```

云环境可使用现有 `PLAYWRIGHT_MODULE=/workspace/environment-onboarding/playwright.cjs` 适配平台 Chromium。桌面和移动端截图、测试结果保存在 `qa/website-*`，不随源码交付。
