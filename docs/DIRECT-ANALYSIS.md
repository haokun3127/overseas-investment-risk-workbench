# 资料直接参与模型分析

按用户要求取消逐项外部AI授权功能。授权复选框、详情设置表单及对应修改接口已移除；资料列表、公司概览和补充材料不再显示授权状态。

- 资料与分析页：上传或手动录入后直接提交风险分析任务，不需要勾选授权或自动分析；模型配置、规则等实际条件不满足时，保留资料并显示未启动原因。
- 知识库：资料自动进入中文摘要和检索处理范围，并可作为所属公司或公共范围内的分析依据。
- 公司背景：按提交时固定的公司档案进入分析，不再受旧授权字段控制。
- 补充材料：文本、附件和重新分析路径均不再检查逐项授权；提交前仍检查归属、隔离状态、大小及关联关系。
- 网站来源：录入和运行不再需要外发授权。原有启停和调度时间继续生效；移除授权不会自动启用已停用的网站。

数据库保留旧 `allow_external` 字段和旧请求字段以兼容存量数据与回滚，但它们不再作为分析、检索、摘要或公司背景的准入条件。新保存的真实资料和公司档案统一按可分析处理；即使存量字段是0或旧客户端传false，仍能正常处理。旧修改授权接口不可再切换使用范围。

企业数据访问隔离、登录校验、演示资料限制、资料隔离、模型配置检查、风险规则确认、重复任务去重与历史版本保留继续有效。取消授权不会自动重跑已有风险分析。

验证包含：无授权字段的上传与录入、遗留false字段的任务预检和真实工作线程路径、公司背景快照、知识检索和摘要、补充材料、网站来源及企业隔离。模型结果在隔离测试中用受控响应替代，避免测试向正式模型发送资料；线上验证以现有任务预检和后台处理状态为准。
