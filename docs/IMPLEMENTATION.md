# 一期实现与验收交接

## 实现范围

本次交付已实现单机可运行的 API 接入版业务系统：资料导入、本地检索知识库、风险分析队列、任务取消与前置检查、风险事件页面、原文依据、业务复核历史、可打印风险简报、模型和规则配置、模型合成连接检查、运行状态、历史版本及基本运维工具。

没有预设真实供应商或模型；未使用任何用户 API 密钥。用户正式数据目录为 `data`，浏览器测试独立使用 `qa/ui-data`。

## 下一次真实 API 联调

1. 甲方确定 API 服务及测试资料外发范围；服务器运维人员填写 `.env`。
2. 业务人员在工作台确认正式分类分级规则，建议单独标记规则版本。
3. 导入少量风险、非风险及资料不足案例，检验输出结构与引用。
4. 记录识别准确率/召回率、分类和等级一致率、引用正确率及专家复核意见。
5. 若输出协议、错误率或长文本表现不满足要求，调整模型、提示词或分段策略后复测。

## 当前明确限制

单管理员、单进程、单机验证系统；无自动 OCR、向量语义检索、资料自动抓取、法规时效自动校验、复杂权限、生产高可用或容灾。长文分段分析的跨段事件关系需人工核验。API 计费口径由具体服务决定，系统保存服务返回的用量信息但不估算费用。风险简报是浏览器打印版，不替代甲方正式签发模板；任务筛选范围默认为最近100条任务。

## 交付操作

正式工作台不预置管理员密码。首次打开本机页面后自行创建；通过“载入演示案例”可选择体验虚构数据。配置真实模型后，对真实资料运行任务。部署与备份恢复完整命令见 README.md。
