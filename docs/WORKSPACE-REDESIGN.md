# 工作区重构 · 2026-09-14

本轮保留 FastAPI、SQLite、模型接口与既有路由，重构前端布局和风险核验操作。配色为冷白、浅灰蓝、钴蓝，风险等级保留独立语义色。组件遵循 40px 桌面控件、44px 移动触控、7px 控件圆角、12px 面板圆角和轻蓝灰阴影；正文 14px，表格 13px，辅助信息 11–12px。

## 布局和操作

- 总览采用主分析区和右侧复核区。风险统计并入分布面板，分类排行与分布图切换，点击分类进入相同范围的事件筛选。排行使用当前范围全部类别，长度相对最大类别，数值为事件数量；不推断趋势或因果关系。
- 风险事件采用筛选工具栏、事件表和就地核验面板。完整详情链接保留。就地核验支持摘要、影响、建议、引用原文、复核保存和历史详情入口。
- 复核草稿按事件编号暂存在内存，切换事件可恢复；刷新或关闭页面清除。异步读取有请求序号和 DOM 生命周期检查，过时响应不替换新面板。保存时禁用表单，避免保存期间发生输入覆盖。
- 保存后更新当前行与面板的复核状态，保留列表位置；重新查询更新筛选成员和统计。错误显示并支持重试。
- 资料和知识库采用列表优先、右侧导入与说明的布局。窄屏改为纵向排列。现有文件上传、手动录入、授权选项、筛选与分析操作继续使用原接口。
- 导航支持桌面收起，移动端保留可横向滚动的中文导航。手机上的核验面板进入文档流，点击核验后滚动到面板。

## 代码组织

`web/workspace.js` 负责布局组合与新增交互，`web/workspace.css` 定义工作区视觉。基础渲染、业务增强和任务流程继续分别位于 app.js、features.js、workflows.js。所有资源均由本地服务提供，没有运行时 CDN 或远程字体依赖。未迁移到 Vue/React，也未复制第三方组件源码。

## 验证

隔离 QA 数据库运行浏览器验证，不操作正式业务数据。原有三个浏览器脚本覆盖主流程、功能持久化、任务与报告。新增 `scripts/ui_workspace_test.cjs` 覆盖导航收起、图表排行筛选、就地核验草稿、原文定位、复核数据库持久化及移动端无页面横向溢出。

首次主流程测试发现内联宽度被 CSP 拦截，改为原生 progress 后通过。保留 `style-src 'self'`，没有放宽安全策略。
