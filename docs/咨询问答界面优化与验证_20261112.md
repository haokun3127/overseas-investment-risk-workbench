# 咨询问答界面优化与验证

日期：2026年11月12日  
线上版本：`20261112-workflow-r7`

## 界面变化

- 沿用工作台现有配色、导航和外部模型接入方式，咨询内容使用居中的单一阅读列。
- 问题、回答正文、资料缺口、依据来源分别组织；取消回答内部的重复边框，避免正文被多层容器压缩。
- 桌面回答正文16px、1.95倍行高；手机15px、1.95倍行高。调整段间距、模块标题和长文本换行。
- 证据不足先说明判断限制，再展示有依据支持的内容，随后列出缺失事实、依据、矛盾、受影响判断及补充建议。
- 来源默认收起，保留引用数量。点击正文引用编号会展开来源并将焦点定位到相应片段；“查看原文”继续使用真实全文和引文高亮。
- 新增“复制回答”，复制正文、判断限制、资料缺口和引用来源。剪贴板不可用时给出手动复制提示，不误报成功。
- 咨询报告保留分模块标题、Word下载与打印。打印时自动展开引用，结束后恢复展开状态。
- 输入框、输出形式及发送按钮重新排列；提交期间显示处理状态并阻止重复提交。调用失败保留之前的回答和未发送成功的问题。

## 验证

相关回归30项通过，见 `qa/consultation-ui-20261112/regression.xml`。

本地浏览器覆盖空状态、普通回答、部分回答、报告、无依据、服务失败及剪贴板失败。测试包含来源展开、焦点定位、原文高亮、复制内容、Word链接及打印状态恢复。合成响应仅用于界面验收，没有将其写入生产或描述为真实模型分析。

四种主要状态在1440px和390px成批截图，并检查900px、720px和320px宽度；没有横向溢出、浏览器异常。截图位于 `qa/consultation-ui-20261112/`。
