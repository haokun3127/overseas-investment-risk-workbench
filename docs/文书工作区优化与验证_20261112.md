# 文书工作区优化与验证

日期：2026年11月12日  
发布版本：`20261112-workflow-r8`

## 需求与借鉴范围

针对文书生成内容过短、编辑流程分散、预览和导出不便的问题，只读检查服务器 `/opt/wuye_agent` 的模板填充、缺项识别、公文直接编辑、修改保存和 Word 导出代码。没有复制物业业务资料、账号配置或模板分类，没有修改物业项目。

借鉴的是操作流程：模板与事实分开输入、未知字段保留、以完整成稿为编辑主体、保存后再导出，以及重新生成前保护手动修改。RAG 继续使用自身的权限、知识检索和引用核验。

## 已实现

1. 文书采用独立协议，不再受咨询回答最多4段、每段700字的限制。最多60章、每章6000字、全文40000字；模板中可识别的编号章节须完整且顺序一致，缺章拒绝保存。
2. 模板里的 `{{字段}}` 和 `【待补充：字段】` 显示为可填写项。事实材料支持 Word、文本型PDF、TXT、Markdown，提取后带入事项正文供核对；超长材料报错，不静默截断。
3. 起草、历史文书、模板管理使用页内独立入口。生成后事项输入收起，成稿成为页面主体，可重新展开材料；正文按宽度自动展开，手机不截断正文。
4. 直接修改章节标题与正文；保存说明、修改记录和 revision 并发保护保留。未保存时阻止下载和模型修改，避免下载旧正文或覆盖手改稿。
5. 按修改要求另存新稿，保存原稿关联、模板快照、事实、字段及起草要求。失败保留原稿与输入，历史列表成功后刷新。
6. 区分事实、模板约定和法律结论的引用要求；法律结论必须有已记录为有效的法律来源。引文原文和金额校验继续执行，模板或新闻不能充当已确认的法律依据。校验不等于语义及法律适用的专业终审。
7. Word 采用A4、宋体正文、黑体标题、Times New Roman西文，正文按段落排版，待补字段突出显示，核对事项及引用来源另页展示。人工修改后的引用仅保留为生成来源，不宣称重新核验通过。
8. 修复明确人民币表达“100万元人民币”“人民币100万元”可能漏过金额识别的问题，不推断没有明确币种的金额。
