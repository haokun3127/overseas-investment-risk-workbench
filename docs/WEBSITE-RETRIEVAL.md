# 指定网站 AI 检索与风险预警

入口：工作台导航中的“网站检索”。网站未最终确定时，无须在代码中写死域名。

## 使用流程

1. 添加网站：填写名称、公开网站或栏目入口、关键词或主题；每次最多访问1至20页。
2. 授权：外部模型模式下，明确允许该网站正文发送至已配置AI服务。沿用服务端模型、Responses协议、低推理及禁止响应存储的配置。
3. 开始检索：后台从入口跟随同域、同协议、同栏目路径的链接，采集正文，再调用AI判断相关性。可取消，可离开页面后重新查看记录。
4. 核验结果：查看原始网址、抓取时间、正文、相关性说明和连续原文引用。不相关页面不可入库；AI引用无法定位则整次任务失败。
5. 入库：选择相关页面，保存为知识库参考资料、风险资料或两种用途。知识库提供现有 BM25 检索及风险分析引用；风险资料可同时排队分析。
6. 预警：发现的风险进入“风险事件”和首页待复核事项，保留原文依据，供人工确认。这是站内预警，未配置邮件、短信或其他对外推送。

## 定时采集

默认手动检索。可设置每6小时、每天或每周运行；也可选自动入库及对新风险资料自动分析。自动分析要求风险规则已确认，且外部模式授权有效。

定时功能由原有隔离服务内的独立采集队列执行，每次只执行一个采集任务；风险分析沿用独立分析队列。网站可编辑、暂停定时；暂停不取消正在执行的任务，需要另点“取消检索”。服务重启将执行中的采集标为失败，待排队任务可继续。

## 数据与边界

- 同域同路径限制、所有DNS地址公网校验、固定已验证IP连接、HTTPS证书验证、每次跳转重新校验，禁止访问本机、内网及云元数据地址。
- 遵守 robots.txt；404视为未提供规则，其他读取失败阻止采集。每次请求至少间隔1秒，并遵循站点声明的 crawl-delay。
- 每页上限1MB、正文60000字符，最多20个访问页面。保留不可变原始快照及抓取正文、网址、抓取时间、摘要指纹、相关性判据和入库关联。
- AI每页审核前6000字符，最多4页一批；不允许AI补造网址。网页中的指令被视为不可信数据。
- 按资料用途、标题和正文去重；相同资料重复入库不新增，已分析的相同风险资料不重复自动分析。变化后的内容形成新资料；重复抓取的审查记录仍保留。
- 仅支持可直接读取的公开HTML和文本页面。暂不支持需登录、JavaScript渲染、压缩响应、PDF等附件正文或站点搜索接口。只能检索当前访问预算内可发现的页面，不承诺穷尽整个网站；真实网站确定后应测试栏目入口和页面结构。
- 网页发布时间仅提取明确的日期元数据；抓取时间单独保存，不冒充发布时间。
- 默认不配置任何业务监测网站，也不自动外发业务资料。验收可以使用明确标为连接测试的公开示例域名，结果不应导入正式知识库。

## UI 调整

首页统计、最新风险和复核待办优先展示；分类图移至后方并默认展示排行。资料列表区分分析结论，零选择时禁用分析，显示演示资料限制。知识库和资料页均可进入网站检索。模型状态使用已完成分析记录，不把配置状态当实时连通状态。移动端改为展开菜单，详情先展示依据，再展示复核表单。
