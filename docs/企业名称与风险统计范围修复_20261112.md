# 企业名称与风险统计范围修复记录

日期：2026年11月12日  
上线版本：20261112-workflow-r4

## 问题与原因

1. 企业下拉框仍显示 `〔S1〕`、`〔S2〕`。之前的清理覆盖了资料与事件名称，遗漏了企业档案及其知识资料标题。
2. 管理员侧栏显示“全部公司”，风险总览却只显示1条。管理员登录会继承旧的全局 `active_company=1`，实际统计限定在TikTok企业；侧栏没有同步显示这一选择。

## 修复内容

- 清理19份企业档案各展示字段中的资料准备编号，以及19份关联档案标题。
- 企业接口和保存入口统一清理相同编号，原文引用、源资料正文、历史模型输入和人工复核记录保留。
- 新管理员会话默认使用全部企业范围，不再继承旧的全局公司选择。
- 部署时将现存5个管理员会话恢复到全部企业，企业用户的归属和权限保持不变。
- 管理员侧栏与当前企业范围同步，清理“切换企业不会过滤统计”等过时说明。
- 后续案例重放与数据同步按稳定ID或规范化名称唯一匹配企业；无法唯一确认时停止，避免误将资料写入无归属范围。
