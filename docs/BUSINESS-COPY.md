# 业务页面文案清理

本轮按用户要求清理录入与演示准备期间附加的说明，让日常页面直接展示资料、风险及处理事项。

覆盖风险总览、事件列表与详情、资料与分析、知识库、网站检索、网站更新、补充材料、分析任务、风险简报、分级对策库、设置，以及登录页和原文弹窗。

- 去除“客户测试”“已抓取”“适用性待核验”等来源附加文字、通用页面脚注、重复的解释段落和英文辅助眉题。
- 清除仅用于初始化的公司关注项/备注、从这些备注衍生的摘要尾句和从未由人工填写的预填复核意见。原始业务事实、原文、模型分析、引用、等级和实际人工处理记录不改写。
- 网站更新中的待处理/已处理状态替代原待核验/已核验标签；底层状态、数量和处理动作不变。
- 页面未经过模型相关性筛选时显示“未筛选”；不显示空白的“AI判定依据”或用采集说明冒充模型结论。
- 失败、隔离、未筛选、待处理等实际状态、时间、来源链接和机构职责继续显示。

文案检查使用明确的初始化文字清单；不对业务原文中的“客户”、合同核验要求或模型判断里的具体待核实事项进行全局删除。历史模型输入和内部溯源保留。

在隔离数据副本中检查12个页面的桌面和390px手机布局，共24个视口；另外展开网站结果与更新事项。检查目标文案、状态标签、脚本错误和页面横向溢出。原有分级对策、网站更新和版本接口回归继续运行。无新增模型调用要求。
