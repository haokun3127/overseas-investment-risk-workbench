# 跨页面 null 报错修复与验证

日期：2026年11月12日  
线上版本：20261112-workflow-r9

## 问题与原因

咨询问答等页面出现 `Cannot set properties of null (setting 'onsubmit')`。
应用每次渲染后都会调用各功能的绑定函数。r8新增的文书工作区绑定函数没有先判断当前页面，访问不存在的模板表单并设置 `onsubmit`，使整个页面进入渲染错误状态。这是上一轮文书改动引入的缺陷。

## 修复

- 文书工作区绑定前检查工作区及模板表单是否存在；其他页面直接返回。
- 提升页面版本及文书脚本缓存版本，确保重新打开页面可获得修复。
- 检查其他表单绑定入口，已有页面或元素存在性判断；本轮未改其业务逻辑。
- 新增回归：去掉修复后必须重现空DOM异常，加回修复后不得报错。
